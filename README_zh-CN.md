# SAI2 绘画工具包 0.2.0

这是 Windows x64 上的独立工具，不是安装进 SAI2 的插件。「录制」和「3D 人偶」包含在同一个 Windows 发行包内，通过主窗口的两个分页进入。

## 3D 人偶

完整解压 Windows 发行包，双击 `SAI2CanvasRecorder.exe`，在「3D 人偶」页点击「打开 3D 人偶」。不需要启动 SAI2 或安装 FFmpeg。

**使用已有的 hinzka 模型：** 在普通版点「模型」旁的文件夹，导入原来的 VRM。对与试用版完全相同的 [hinzka 男女 VRM](https://github.com/hinzka/52blendshapes-for-VRoid-face)，程序默认使用 `UpperChest` 作为躯干控制点，保留灯光响应，并沿用本机原有的姿势和骨骼映射。作者 README 与 VRM 内嵌再分发许可不一致，程序不随包分发原模型，也无需单独的试用版。
- 成功绑定的人形导入模型使用自己的肩位、臂长和朝向套用姿势，并应用预设手腕角度。「初始姿势」恢复模型原始姿势。模型的关节结构、朝上方向或蒙皮与标准人形差异较大时，仍需手动调整骨骼映射或姿势。
- 「模型」下拉框可在原版灰模和五款二次元素体之间切换：男生少年、成男；女生萝莉、少女、成女。内置素体按头身比、肩胯和四肢比例区分，使用中性灰模材质，不附发型或服装。
- 从六种预设开始，拖动视图中的手脚控制点改变位置。相机可旋转、缩放，并切换透视或正交。
- 点模型上的关节点，拖动出现的彩色旋转环。手腕、脚踝可三轴旋转；肘、膝的环改变弯曲朝向，不改变手脚目标位置。每次只显示一个部位的旋转环，点视图空白处或按 `Esc` 可取消选择。手脚控制点本身依然可以拖动，用来改变位置。
- 脚踝的零位随小腿转动，脚尖抬压沿脚踝局部轴覆盖一整圈。滑块显示 `-180°` 到 `180°`，旋转环可继续跨过这个边界；脚掌侧倾与脚尖内外转仍保留各自的角度限制。
- 手掌翻转同样覆盖 `-180°` 到 `180°`，可拖旋转环跨过边界。手腕的弯伸与侧偏范围不变。
- 原版灰模、hinzka 两款模型和带独立肩骨的导入模型可分别调整左右肩。上下拖动肩上的双向箭头，或选中肩部后用「肩部升降」滑块。抬肩时会转动锁骨，并尽量保持同侧手腕的摆放位置；肩部调整可随自定义姿势保存。导入时也可在「骨骼映射」里手动指定左右肩；没有独立肩骨的模型不会显示对应控制点。
- 胯部、躯干均可前后倾、左右转向、左右侧倾；转动胯部时躯干跟随，四肢继续朝原本的手脚目标解算，超出可达范围时会停在可达位置。头部随躯干移动，也可独立抬低、转向、侧倾。
- 「关节角度」可从下拉框选择部位，并用滑块精确微调。部位旁的重置按钮仅清零该部位的角度；切换姿势预设会重置整体姿势。
- 在「自定义姿势」输入名称，点击保存图标。之后可从下拉框载入或删除；同名保存会询问是否覆盖。保存的是骨骼姿势和手脚目标位置，不包含相机或灯光，数据保留在本机 3D 窗口的 WebView2 用户数据中，不随压缩包复制。
- 拖动工作区右上角的光球来转动主光：实心光点表示光源在当前视角前方，空心光点和虚线表示在背面。侧栏可精调主光方向、高度、主光与补光强度。
- 在右上角选择 PNG 长边分辨率（1024、2048 或 4096 像素，默认 2048），再点「透明 PNG」。按所选像素重新渲染，保留当前构图、宽高比及透明背景，不含操作控件。需要更清晰的边缘可选择 4096；导出失败时可降低一档再试。
- 3D 窗口使用本机的 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)，内置素体随包提供，运行时不需要联网下载。

### 导入自己的模型

1. 点「模型」旁的文件夹按钮，每次选一个 `.glb`、`.gltf`、`.fbx` 或 `.vrm` 主文件。推荐优先用自包含 `.glb`。若主文件引用单独的 `.bin` 或贴图，请在同一对话框中将它们一并多选，资源文件名需唯一；不读取网络引用。
2. 导入后从模型的初始姿势开始。VRM 优先按人体骨骼元数据识别，其余按常见命名匹配。识别失败时，展开「骨骼映射」补选骨骼，再点「应用骨骼映射」。未绑定或非人体骨架可旋转查看和导出 PNG，不启用摆姿势。
3. 自定义姿势和骨骼映射按模型分别保存在本机。导入文件不会被复制进项目；关闭后要使用导入模型的姿势，需重新导入同一个主文件。窗口内保留最近一次导入的模型，可和内置模型来回切换。

导入面向人体静态参考，适合 Y 轴向上、正面朝 +Z 的常规骨骼。VRM 0.x 会根据元数据调整朝向。不承诺还原原工具中的动画、表情、弹簧骨或 VRM MToon 材质。暂不支持 PMX 和需要额外解码器的压缩模型、纹理。

## 开始录制

1. 在已构建的本地项目中可双击 `launch_recorder.cmd`。使用 [GitHub 发行包](https://github.com/YUMI233666/sai2-canvas-recorder/releases) 时，下载名称带 `-external-ffmpeg.zip` 的 Windows 包并完整解压（保留 `_internal`）。无需另装 Python；请将带 `libx264` 的 [Windows 版 FFmpeg](https://ffmpeg.org/download.html#build-windows) 中的 `ffmpeg.exe` 放在 `SAI2CanvasRecorder.exe` 同目录，或将它的目录加入 `PATH`，再启动录制器。
2. 打开 SAI2 和画布，回到录制器，必要时点「刷新」。选中 SAI2 进程后点「连接画布」，再选要录制的画布，确认预览完整。
3. 选择采集来源、模式、输出参数和保存位置，点「开始录制」。弹出目录选择时，同一作品选择已有目录，不同作品选择「新建画布目录」。暂停和继续只影响当前这一次录制。
4. 点「停止并导出」，等待导出完成。点「打开输出」进入画布目录，查看这幅画的各次成片。

窗口较矮时，可用鼠标滚轮或右侧滚动条访问底部按钮。参数在录制和导出时锁定，结束后可调整。`F8` 可以开始或停止录制，但只在录制器窗口有焦点时生效。

## 选采集来源

| 来源 | 会录到什么 |
| --- | --- |
| 整画布（固定构图） | 只录画布合成图，构图不随窗口缩放、平移或旋转变化，不含界面或鼠标。若 SAI2 在抬笔时才更新合成图，实时模式也只能录到整条线一次出现 |
| 笔画过程（SAI2 窗口） | 采集所选 SAI2 进程的主窗口，录入窗口正在显示的画面，包括落笔中途已显示的部分、工具栏和画布视图变化。不是桌面录制 |

要检查线条是否随笔尖逐步延伸，选 **「笔画过程（SAI2 窗口）」+「实时录制」**，先用 `30 FPS` 试录。开始前在 SAI2 中切到要录的画布，并保持它为活动文档：录制器选中的画布用于归档，窗口模式录到的是 SAI2 当前显示的内容。录制前设好窗口大小，录制中不要最小化或调整窗口大小；遇到这两种变化会停止采集并尝试导出已有画面。连接后的静态预览仍为整画布，开始录制后才显示窗口采集预览。

## 选实时还是延时

| 模式 | 适用场景 | 视频时长 |
| --- | --- | --- |
| 实时录制 | 想保留真实时长和停顿 | 按实际录制时长播放，暂停时间不计入。漏采时用已有画面补帧，无法补出来源未提供的笔画中间态 |
| 延时录制 | 想快速回看绘画过程 | 每张保留的采样图只写成一帧；可输入 `0.1` 到 `60` 秒，支持小数，也可跳过静止画面 |

**采样间隔不是视频帧率。** 例如每 `0.5` 秒采一次，录制 `30` 秒，理想情况下采到约 `60` 张图；按 `30 FPS` 播放就只有约 `2` 秒。开启「延时模式跳过静止画面」或者漏采后，成片可能更短。缩短采样间隔能保留更多笔画中间状态，但不能让延时模式还原真实落笔速度；要保留实际速度，选实时录制。

## 输出参数

| 参数 | 可选项或说明 |
| --- | --- |
| 输出长边 | 1280 / 1920 / 2560 / 3840 / 采集原始尺寸。只等比缩小，不放大、不裁图 |
| 视频帧率 | 15 / 24 / 30 / 60 FPS。输出帧率不等于实际采样速度 |
| 画质 | CRF 16 / 20 / 24 / 28，数值越小，画质通常越高、文件越大 |
| 编码速度 | 优先速度 / 快速 / 均衡 / 优先压缩 |
| 视频格式 | MP4 或 MKV，均为 H.264，无透明通道 |

整画布模式下，`3000 × 2000` 画布用 `1920` 长边会得到 `1920 × 1280` 视频；窗口模式则按窗口比例输出。若等比缩放后出现奇数尺寸，编码时只在右侧或底部补一个像素。实际采样速度受采集尺寸、输出尺寸和编码负载影响，面板会显示平均采样速度、跳过次数和读取耗时。

## 找成片、清理和恢复

默认保存位置是当前用户的 `Videos\SAI2录制`。同一画布可以录多次，每次成片按时间命名，放在同一个画布目录，互不覆盖。关闭软件后，可以重新连接画布，在开始录制时选择原目录。名称和尺寸相同的目录会排在前面，但这不是同一作品的证明；遇到同名的不同作品，应选「新建画布目录」。重新连接前，录制器会记住这次连接中已经确认过的画布目录。

```text
SAI2录制/
  画布-海边-12ab34cd/
    canvas.json
    20261118-140000-7a2b3c.mp4
    20261119-153000-4d5e6f.mp4
    _sessions/
      20261118-140000-7a2b3c/
        session.json
        parts/
        encoder.log
```

旧版已有输出不会自动迁移。本版只归档各次成片，不会跨次自动合成总视频。

| 文件 | 用途 |
| --- | --- |
| `日期-时间-编号.mp4` / `.mkv` | 单次录制的成片，导出成功后在画布目录生成 |
| `canvas.json` | 画布目录的标记和原始名称、尺寸，用于后续选择目录 |
| `_sessions/<录制编号>/parts/` | 本次录制写入的 MKV 分段，默认按约 `60` 秒**视频时长**切分 |
| `session.json` | 会话信息，恢复分段需要此文件 |
| `segments.csv`、`concat.txt` | 分段清单与合并清单 |
| `encoder.log`、`export.log`、`error.txt` | 编码、导出和错误记录，部分文件仅在相应操作或出错时出现 |

**成片能正常播放，且确认首尾完整后，可以手动删除该会话的 `parts/`。** 这不会影响成片，但删掉后就不能从分段恢复本次录制。分段在正常导出后仍会保留，因此同一会话会多占用接近一份成片的空间。

**没有成片、导出失败或成片不完整时，先不要清理。** 保留 `parts/` 和 `session.json`，点「恢复分段」，选择 `_sessions/` 下包含这两项的那次录制目录。工具会将可解码的分段合并为画布目录下新的 `录制编号-recovered-日期时间.mp4` 或 `.mkv`，不会覆盖原成片。旧版输出仍可选择原会话目录恢复，恢复文件保存在原会话目录。损坏的分段或尚未写入磁盘的帧不保证能找回。

## SAI2 兼容性与排查

- 整画布模式支持读取已适配的 64 位 SAI2 画布，单次只录一个画布，上限 `6400` 万像素。切换活动文档不会换掉录制目标。目标画布关闭、像素尺寸改变或 SAI2 退出时，录制器会停止并尝试导出已有画面。
- 笔画过程模式仍需连接画布来选择归档目录；采集本身通过 [Windows Graphics Capture](https://learn.microsoft.com/windows/win32/api/windows.graphics.capture.interop/nf-windows-graphics-capture-interop-igraphicscaptureiteminterop-createforwindow) 获取窗口。若启动提示采集失败，先还原并保持 SAI2 窗口可见；该模式不会自动改为桌面采集。
- 内置指定指纹的 SAI2 `2023.04.05` 专版（MD5：`9da34848ba9e6993a40262b462e0445d`）。打开画布后直接点「连接画布」。录制器不会修改 SAI2 安装文件。
- 连接失败时，先确认画布已打开，且录制器和 SAI2 以相同权限运行。未适配的版本可尝试「识别此版本」，但识别成功不代表已通过录制兼容性验证；应先确认预览再试录。
- 需要反馈时，点「保存诊断」，并附上失败步骤和画布尺寸。诊断包含程序路径、指纹、错误和统计，不包含画布图像或内存转储。打包版设置、识别缓存和应用日志位于 `%LOCALAPPDATA%\SAI2CanvasRecorder`，源码运行时位于项目根目录。

整画布读取连续失败约两秒时会停止。快速绘画时，整画布分块可能来自不同的更新时刻；当前版本的录制兼容性和性能仍由用户实机验收，见[手动验收清单](MANUAL_ACCEPTANCE.md)。

## 从源码运行或打包

需要 64 位 Python 3.14 或更高版本，以及 `uv`。构建 3D 时还需 Node.js、npm、.NET SDK 与 .NET Framework 4.8 开发包。在项目根目录执行：

```powershell
uv sync --extra dev --locked
powershell -ExecutionPolicy Bypass -File .\build_pose_studio.ps1
.\.venv\Scripts\python.exe -m sai_recorder
```

打包使用以下命令，产物位于 `dist/`。该命令不会启动 SAI2 或执行录制测试。

```powershell
powershell -ExecutionPolicy Bypass -File .\build_recorder.ps1
```

以上命令产出本机自用包。制作外置 FFmpeg 版时，加 `-ExternalFfmpeg`，产物位于 `dist/github/`。外置版也可通过环境变量 `SAI2_FFMPEG_EXE` 指定 `ffmpeg.exe` 的完整路径。

如果本地 `.venv` 已装好依赖，且已构建 3D 组件，可以用 `.\.venv\Scripts\python.exe .\tools\build_recorder.py` 直接打包。整理本地目录时，可删除 `build/` 和 `.cache/`；继续使用现有开发环境时，保留 `.venv/` 与 `.runtime/`。只运行打包版时，保留当前版本的完整程序目录即可。
